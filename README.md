# Consulting Deliverable Templates & Guides

Reusable assets for consistent, high-quality consulting output.

## Templates

| Template | Use When | Typical Duration |
|----------|----------|-----------------|
| [Strategy Deck](templates/strategy-deck/TEMPLATE.md) | Strategic recommendations to client leadership | 2-4 weeks |
| [Implementation Plan](templates/implementation-plan/TEMPLATE.md) | Detailed execution blueprint for an initiative | 3-6 weeks |
| [Research Report](templates/research-report/TEMPLATE.md) | Market research, competitive analysis, data-driven recommendations | 1-3 weeks |
| [Technical Assessment](templates/technical-assessment/TEMPLATE.md) | Technology evaluation, architecture review, technical due diligence | 1-4 weeks |
| [Case Study](templates/case-study/TEMPLATE.md) | Post-engagement — capture outcomes for business development | 1 week |

## Guides

| Guide | Purpose |
|-------|---------|
| [Research Methodology](guides/research-methodology.md) | Standard approach for market research, competitive analysis, and data-driven recommendations |
| [Workshop Facilitation](guides/workshop-facilitation.md) | How to run discovery sessions, strategy workshops, and review meetings |

## How to Use

1. **Starting an engagement:** Pick the template that matches the deliverable type. Copy it into the engagement folder.
2. **During the engagement:** Follow the Research Methodology guide for any research work. Use the Workshop Facilitation guide for client sessions.
3. **Closing an engagement:** Complete the Case Study template within one week of engagement close.
4. **Quality gate:** Use each template's built-in Quality Checklist before delivering to the client.
