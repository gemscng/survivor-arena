# Change Order Process

## Overview

Scope changes are inevitable. This process ensures they are documented, priced, and approved before work begins — protecting both Thea and the client.

---

## 1. What Triggers a Change Order

A Change Order is required when any of the following change after SOW execution:

| Change Type | Examples |
|-------------|----------|
| **Scope addition** | New deliverable, additional analysis, expanded audience |
| **Scope reduction** | Removing a deliverable, narrowing scope (may reduce fee) |
| **Timeline change** | Extension or acceleration of the schedule |
| **Staffing change** | Adding roles not in original SOW, upgrading seniority |
| **Assumption invalidated** | Client environment differs materially from what was assumed |

**Does NOT require a Change Order:**
- Minor clarifications within existing scope
- Rescheduling meetings within the same milestone window
- Swapping equivalent team members (same role/rate)

## 2. Process Flow

```
1. Identify Change
       |
2. Log in Change Request Register
       |
3. Assess Impact (cost, timeline, risk)
       |
4. Draft Change Order
       |
5. Internal Review (EM reviews, CEO approves if > $5K or > 2 weeks)
       |
6. Present to Client
       |
7. Client Decision (Approve / Reject / Negotiate)
       |
  [If Approved]          [If Rejected]
       |                       |
8. Append to SOW         Document decision,
   Begin work             continue per original SOW
```

## 4. Decision Authority

| Change Size | Internal Approval | Client Approval |
|-------------|-------------------|-----------------|
| < $5K and < 1 week impact | Engagement Manager | Client sponsor |
| $5K-$25K or 1-4 weeks impact | EM + CEO | Client sponsor |
| > $25K or > 4 weeks impact | EM + CEO | Client exec sponsor |

## 5. Change Request Register

| CO # | Date | Description | Impact ($) | Impact (Timeline) | Status | Decision Date |
|------|------|-------------|-----------|-------------------|--------|---------------|
| CO-001 | [Date] | [Brief] | +$[Amt] | +[N] days | Approved / Rejected / Pending | [Date] |

## 6. Rules of Engagement

1. **No work before approval.** Never begin out-of-scope work before the Change Order is signed.
2. **Proactive identification.** If you see scope creep forming, flag it immediately — don't wait for it to become a problem.
3. **Client education.** During kickoff, walk the client through the change order process so there are no surprises.
4. **Fair pricing.** Change orders should be priced consistently with the original SOW rate structure.
5. **Audit trail.** All change orders are appended to the SOW and stored in the engagement file.
6. **Two-way street.** Clients can also request scope reductions — handle these with the same rigor and adjust fees accordingly.
